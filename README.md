# Mindaz — Minecraft 1.21.4 Fabric

Оружие **Mindaz**:

- Острота VII
- Заговор огня II
- Прочность V
- ПКМ: создаёт до 3 белых блоков шерсти под игроком.
- Шерсть исчезает через 10 секунд.
- Перезарядка способности: 30 секунд.
- Не заменяет существующие блоки: способность ставит шерсть только в воздух.

## Сборка на GitHub

1. Создай новый репозиторий на GitHub.
2. Загрузи все файлы этого проекта в репозиторий.
3. Открой вкладку **Actions**.
4. Запусти workflow **Build Mindaz** через **Run workflow** или сделай push.
5. После успешной сборки открой запуск workflow и скачай artifact `mindaz-mod`.
6. Внутри будет JAR-файл мода.

## Установка в PojavLauncher

1. Установи Minecraft Java Edition 1.21.4.
2. Установи Fabric Loader для 1.21.4.
3. Положи собранный `mindaz-1.0.0.jar` в папку `mods`.
4. Положи туда же Fabric API версии для 1.21.4.
5. Запусти профиль Fabric.

Для разработки и сборки используется Java 21.
